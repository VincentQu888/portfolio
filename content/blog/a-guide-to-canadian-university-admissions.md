I've wanted a place to write for a while — somewhere that isn't a feed, an
algorithm, or someone else's platform. So here it is.

The plan is simple: keep it minimal, keep it honest, and actually publish. No
fancy CMS, no analytics dashboard to obsess over. Just markdown files and a
handful of pages.

## What I'll write about

- Things I'm building, and what broke along the way
- Notes from learning machine learning
- The occasional half-formed idea I want to think through in public

## How this works

Each post is a markdown file in `content/blog/`. Add a file, give it a title
and a date, and it shows up here automatically. That's the whole system.
